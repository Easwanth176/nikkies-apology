# for nikkie

A mobile friendship letter, made to open on a phone and deploy on Vercel.

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). The words live in `src/content/letter.ts`. Wrap any word in `{braces}` to highlight it.

## Deploy

Import this repo in Vercel. Framework preset is Next.js. No environment variables.
